Set up here

  1. You need

    A domain on Cloudflare, and Zero Trust turned on for the account (once: open Zero Trust, pick a team name and the Free plan).

  2. Create an API token

    Cloudflare → API tokens → Create Token → Create Custom Token, with these permissions:

      Account Resources: your account. Zone Resources: the zone your hostname is in. The token is used for the one step you press and is never saved — delete it in Cloudflare afterwards if you like.
