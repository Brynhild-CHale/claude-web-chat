3 · Say something, and watch it queue

Pick what you'd like Claude to do first in this project:

writes web_chat_init

That's the surface

The shell ignores hotkeys while your cursor is in a text field — click anywhere outside one first, or use the Push button on the queue rail at the right edge.

Now go back to your terminal:

  • /exit, then reopen Claude Code in this project. It reads .mcp.json only at startup, so the web-chat tools do not exist until you do.
  • Then type /web-chat init — Claude picks up exactly here.

Worth knowing: ⌘K commands · N components · G the graph of every turn · P push to Claude.

One thing this tour can't show you: the graph. Every Claude turn commits a node under .web-chat/graph/ that you can walk back to and branch from — but only Claude's turns commit nodes, and this page was put here by the CLI, not by a turn. So this project has none yet. /web-chat init shows you the first real one, after the restart.
